Sobre el proyecto

Una tienda en línea hecha con Angular moderno

NgStore es una aplicación de e-commerce de demostración. Consume la Platzi Fake Store API y aplica las prácticas actuales del framework: componentes standalone, signals para el estado, rutas con carga diferida y una arquitectura organizada por dominios.
